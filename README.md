# Detr-s-de-cada-hect-rea
Siete días para entender quién se quedó con la tierra en los Montes de María entre 1990 y 2005. Analizamos informes de memoria histórica, mapas del IGAC y prensa para ver cómo el conflicto armado cambió la tenencia de la tierra y a quiénes benefició. Lectura de 8 minutos, con reloj incluido. Grupo 7, curso CBU Colombia: espacio, tiempo, diferencia.
